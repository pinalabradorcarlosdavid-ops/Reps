# Rutina — Calistenia (PWA)

App de seguimiento de entrenamiento (calistenia avanzada, 5 días/semana) en formato PWA
para iPhone: pantalla completa, tabs Hoy / Semana / Progreso, progreso guardado en el
dispositivo con reinicio automático cada lunes, y detalle por ejercicio (descanso + progresión).

## Archivos
- `index.html` — la app completa (HTML/CSS/JS en un solo archivo).
- `manifest.json` — manifiesto PWA (nombre, íconos, modo pantalla completa).
- `icon-180.png` / `icon-512.png` — íconos de la app.

## Uso
Servir la carpeta como sitio estático (Netlify, GitHub Pages, etc.) y abrir en Safari →
Compartir → "Agregar a inicio".
